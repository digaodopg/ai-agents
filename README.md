# AI Agents — Top 10 do GitHub

Projetos open source de IA em destaque no GitHub, salvos a partir do reel "Top 10 do GitHub" de inema.tds (novembro de 2026).

1. [vercel-labs/agent-desktop](https://github.com/vercel-labs/agent-desktop) — CLI que permite que agentes de IA operem o computador. Rust. ~15,2 mil estrelas.
2. [NVIDIA/auto-ontology](https://github.com/NVIDIA/auto-ontology) — Framework Python para camadas de raciocínio semântico em grafo sobre dados, para LLMs e agentes. ~5,1 mil estrelas.
3. [D4Vinci/Scrapling](https://github.com/D4Vinci/Scrapling) — Framework de web scraping, de uma única requisição a crawls em larga escala. Python. ~96,6 mil estrelas.
4. [JiaFeiMiao-K-Cat/DiscImageStudio](https://github.com/JiaFeiMiao-K-Cat/DiscImageStudio) — Sem descrição publicada no GitHub. C#. ~6,6 mil estrelas.
5. [mattpocock/skills](https://github.com/mattpocock/skills) — Coleção de skills para engenheiros, direto do diretório .agents do autor. ~313 mil estrelas.
6. [thedotmack/claude-mem](https://github.com/thedotmack/claude-mem) — Memória persistente entre sessões para agentes (Claude Code, Codex, Gemini e outros). TypeScript. ~112,9 mil estrelas.
7. [floci-io/floci](https://github.com/floci-io/floci) — Emulador local da AWS, alternativa gratuita ao LocalStack. Java. ~29,7 mil estrelas.
8. [github/spec-kit](https://github.com/github/spec-kit) — Kit de ferramentas para desenvolvimento guiado por especificações (SDD). Python. ~147,3 mil estrelas.
9. [harry0703/MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo) — Gera vídeos curtos em HD a partir de um tema ou palavra-chave, com fluxo automatizado de IA. Python. ~139 mil estrelas.
10. [max-sixty/worktrunk](https://github.com/max-sixty/worktrunk) — CLI para gerenciar git worktrees, feita para fluxos paralelos de agentes de IA. Rust. ~11,1 mil estrelas.
